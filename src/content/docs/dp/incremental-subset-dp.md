## 概要

集合をグループに分割するとき, 次のグループの部分集合を丸ごと選ぶ代わりに, **最後の未完成グループへ要素を1つずつ追加する** DP を考える.

- 使用済み集合を bitmask で管理する
- 完成したグループの詳細は捨て, 最後の未完成グループについて必要な情報だけを残す
- その情報が使用済み集合から決まるなら, DP の添字を増やさずに済む

ビット演算そのものよりも, 状態設計と遷移の工夫が中心となるテクニック.

## 部分集合を選ぶ遷移との違い

使用済み集合 $S$ に対し, 残りから次のグループ $T$ を選ぶと, 全体の列挙数は $3^N$ になる. 各要素が「$S$ に属する」「$T$ に属する」「どちらにも属さない」の3通りだからである.

ここで $3^N$ は部分集合そのものの個数ではなく, 集合とその部分集合の組を全体で列挙する計算量.

一方, 未使用の要素 $i$ を1つ追加する遷移

$$
S \longrightarrow S\cup\{i\}
$$

なら, 各集合につき遷移は高々 $N$ 通り. 集合ごとの状態を1つにまとめられれば, 時間 $O(N2^N)$, 空間 $O(2^N)$ になる.

任意のグループ分けは, 各グループの要素を連続して並べることで表せる. その並びを1要素ずつ作り, グループの区切りを判定する.

## 例: 和が K の倍数になるグループを最大化する

正整数列 $A$ を, 和が $K$ の倍数になる非空グループに分割し, グループ数を最大化する. 全体の和も $K$ の倍数とする.

最後の未完成グループの和の余りを $r$ とすると, 要素 $A_i$ の追加後は

$$
r'=(r+A_i)\bmod K
$$

となる. $r'=0$ ならグループを完成させ, 次のグループを作り始める. 今すぐ区切っても以後の余りは変わらず, グループ数だけが増えるので, この目的では必ず区切ってよい.

完成済みグループの和はすべて $K$ の倍数なので,

$$
r(S)=\left(\sum_{i\in S}A_i\right)\bmod K
$$

が成り立つ. **最後の余りは使用済み集合だけで決まり, `dp[S][r]` と持つ必要はない.**

$dp[S]$ を「$S$ の要素を並べたときの完成済みグループ数の最大値」とする. 末尾に未完成グループが残ることは許す.

$$
dp[S\cup\{i\}]
\gets \max\left(dp[S\cup\{i\}],\ dp[S]+[r(S\cup\{i\})=0]\right)
$$

初期値は $dp[\emptyset]=0$, それ以外は $-\infty$. 同じ集合なら余りも今後の選択肢も同じなので, 完成済みグループ数が最大のものだけ残せばよい.

```cpp
// A は正整数列, K > 0, sum(A) は K の倍数.
// N は 2^N 個の状態を確保できる範囲を想定.
int max_multiple_groups(const vector<long long>& A, long long K) {
    int N = (int)A.size();
    int full = 1 << N;
    vector<long long> rem(full, 0);
    vector<int> dp(full, -1);
    dp[0] = 0;

    for (int s = 0; s < full; ++s) {
        for (int i = 0; i < N; ++i) {
            if (s & (1 << i)) continue;
            int t = s | (1 << i);
            rem[t] = (rem[s] + A[i]) % K;
            dp[t] = max(dp[t], dp[s] + (rem[t] == 0));
        }
    }
    return dp[full - 1];
}
```

`rem[t]` はどの直前の集合から計算しても同じ. また, 要素を追加するとマスクの整数値が増えるので, 昇順に処理すればよい. この例ではどの集合も到達可能である.

## 問題例

### [ABC480-F Cake Cutting](https://atcoder.jp/contests/abc480/tasks/abc480_f)

1人分の大きさを $K=\sum_i A_i/M$ とする. 元のケーキを, 和が $K$ の倍数になるグループへ分割したときの最大グループ数を $g$ とすると, 答えは $M-g$.

- 和が $qK$ のグループを一列に並べれば, $K$ ごとの境界で切ることで高々 $q-1$ 回の切断で配れる. 全グループで高々 $M-g$ 回.
- 逆に, 最終的な $M$ 人分のグループから切断を巻き戻す. 切った2片が別グループにあれば両グループを併合することで, 和が $K$ の倍数という条件を保てる. 1回につきグループ数は高々1しか減らないので, 切断回数は少なくとも $M-g$ 回.

したがって, 上の DP で $g$ を求めればよい. 例えば $A=(7,23)$, $M=3$ なら $K=10$. 余りは $0\to7\to0$ と進み, $g=1$ なので答えは $2$.

参考: [公式解説](https://atcoder.jp/contests/abc480/editorial/27259)

## 適用するときの確認

- 完成済みグループの詳細を忘れても, 次の遷移と評価値を決められるか
- 最後の未完成グループの状態を, 使用済み集合から復元できるか
- 条件を満たした時点で区切ってよいか. グループ数やサイズに別の制約がある場合は, 区切るかどうかの選択や追加の状態が必要になることがある

一般のグループ分けがすべて $O(N2^N)$ になるわけではない. また, この DP は並べる順序を経由するため, 分割の個数を数える用途では同じ分割の重複に注意する.
