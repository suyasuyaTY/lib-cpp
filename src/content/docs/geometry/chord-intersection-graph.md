## 1. 概要

円周上の点を結ぶ弦の交差を、端点の並び順と区間の包含関係に置き換えて考える.
座標や交点を直接計算せず、セグメント木や区間の DP で処理できる.

各弦を頂点とし、交差する2本の弦の間に辺を張ったグラフを**円グラフ（circle graph）**という.
互いに交差しない弦の集合は、このグラフの独立集合に対応する.
ただし、弦が $N$ 本ある場合、交差する組は $O(N^2)$ 個あり得るので、グラフを明示的に構築する必要はない.

## 2. 前提知識

- セグメント木（区間最小値・区間最大値）
- 尺取り法
- 区間の包含関係を使う DP

### 2.1. 交差条件とラミナー性

円周上の端点がない位置を1か所選び、そこから時計回りに点へ番号を付ける.
その位置で円周を切り開くと、弦 $i$ の端点を $L_i<R_i$ として、区間 $[L_i,R_i]$ に対応させられる.

端点を共有しない2本の弦が交差する必要十分条件は、端点が円周上で交互に現れることである.

$$
L_i<L_j<R_i<R_j
\quad\text{または}\quad
L_j<L_i<R_j<R_i
$$

端点を共有しない2本の弦の位置関係は、次のように整理できる.

| 区間の関係 | 端点の並びの例 | 弦の交差 |
| --- | --- | --- |
| 分離 | $L_i<R_i<L_j<R_j$ | しない |
| 包含 | $L_i<L_j<R_j<R_i$ | しない |
| 一部だけ重なる | $L_i<L_j<R_i<R_j$ | する |

**区間が重なっていても、片方が他方に含まれていれば弦は交差しない.**

集合族がラミナーであるとは、任意の2集合 $U,V$ について

$$
U\subseteq V\quad\text{または}\quad
V\subseteq U\quad\text{または}\quad
U\cap V=\varnothing
$$

が成り立つことをいう.
端点がすべて異なる場合、弦の集合が互いに交差しないことと、対応する区間族がラミナーであることは同値である.
端点を共有する場合は、接触を交差に含めるかを問題ごとに確認する.
例えば $[1,3]$ と $[3,5]$ は閉区間としては交わるが、対応する弦は共有端点で接するだけなので、ラミナー性との同値をそのまま当てはめることはできない.

## 3. 交差の判定

### 3.1. 指定範囲に交差があるか判定する

> 問題
>
> 弦が入力順に $1,2,\ldots,N$ と並んでいる.
> 各クエリ $[l,r]$ について、弦 $l,l+1,\ldots,r$ が互いに交差しないか判定したい.
> $N$ 本の弦の端点はすべて異なり、円周上の番号は $1,2,\ldots,2N$ とする.

#### 1本追加するときの判定

現在選んでいる弦が互いに交差しないとする.
新しい弦 $[a,b]$ と既存の弦 $[c,d]$ が交差するのは、次の2通りである.

$$
a<c<b<d
\quad\text{または}\quad
c<a<d<b
$$

そこで、端点の座標を添字にする2本のセグメント木を用意する.

- `right[c] = d`: 左端が $c$ の弦の右端. 区間最大値を取る.
- `left[d] = c`: 右端が $d$ の弦の左端. 区間最小値を取る.

弦のない位置には、それぞれ $0,+\infty$ を置く.
追加する弦と交差する弦がある条件は

$$
\max_{a<c<b}\operatorname{right}[c]>b
\quad\text{または}\quad
\min_{a<d<b}\operatorname{left}[d]<a
$$

となる. 端点は整数なので、ACL の半開区間ではどちらも `prod(a + 1, b)` で取得できる.

```cpp
// 端点の座標を 1..2N のまま使い、木のサイズは 2N+1 とする.
// right: 区間 max、単位元 0. left: 区間 min、単位元 INF (> 2N).
auto can_add = [&](int a, int b) {
    return right.prod(a + 1, b) <= b
        && left.prod(a + 1, b) >= a;
};

auto add = [&](int a, int b) {
    right.set(a, b);
    left.set(b, a);
};

auto erase = [&](int a, int b) {
    right.set(a, 0);
    left.set(b, INF);
};
```

端点がすべて異なるので、各位置に保持する弦は高々1本でよい.
端点がすべて異なるという条件がなくても、`multiset`を使い最大・最小を適切に管理することで判定可能.

#### 尺取り法でクエリをまとめて処理する

弦の集合から何本か取り除いても、交差しないという性質は保たれる.
そこで、左端 $l$ ごとに

$$
\operatorname{limit}[l]
=\max\{r\mid \text{弦 }l,l+1,\ldots,r\text{ が互いに交差しない}\}
$$

を尺取り法で求めることができる.

## 4. 交差しない弦の選択

### 4.1. 交差しない弦の最大本数（最大独立集合）

> 問題
>
> 与えられた弦から互いに交差しないものを選び、交差しない本数を最大化したい.

まず、$N$ 本の弦の端点がすべて異なる場合を考え、円周上の順番に $1,2,\ldots,2N$ と番号を付ける.
点 $l$ を左端に持つ弦の右端を $k=\operatorname{Edge}[l]$ とし、区間 DP を

$$
dp[l][r]=\text{両端点が }[l,r]\text{ にある弦から選べる最大本数}
$$

と定義する. $l\ge r$ なら $dp[l][r]=0$ とする.

点 $l$ を端点に持つ弦を選ぶかどうかで場合分けする.

- 選ばない場合: $dp[l+1][r]$.
- 選ぶ場合: $l < k \le r$ が必要. 弦 $[l,k]$ を選ぶと、残りは $[l+1,k-1]$ と $[k+1,r]$ に分かれる.

この2区間をまたぐ弦は $[l,k]$ と交差するため選べず、両区間の最適解は独立に組み合わせられる.
したがって、$l<k\le r$ のとき

$$
dp[l][r]=\max\left(
dp[l+1][r],\quad 1+dp[l+1][k-1]+dp[k+1][r]
\right)
$$

とし、$l$ を左端に持つ弦がない場合や $k>r$ の場合は $dp[l][r]=dp[l+1][r]$ とする.
$l$ を降順に処理すれば、参照する左端はすべて $l$ より大きいので計算済みになる.

```cpp
vector<int> Edge(2 * N + 1, 0);  // 左端 l に対する右端. 弦がなければ 0.

vector<vector<int>> dp(2 * N + 2, vector<int>(2 * N + 2, 0));
for (int l = 2 * N; l >= 1; --l) {
    int k = Edge[l];
    for (int r = l; r <= 2 * N; ++r) {
        dp[l][r] = dp[l + 1][r];  // l を左端に持つ弦を選ばない
        if (l < k && k <= r) {
            dp[l][r] = max(dp[l][r], 1 + dp[l + 1][k - 1] + dp[k + 1][r]);
        }
    }
}
```

### 4.2. 1本の弦で横切れる最大本数

> 問題
>
> 与えられた弦から互いに交差しないものを選び、さらに新しい弦を1本追加する.
> 新しい弦が選んだ弦と交差する回数を最大化したい.
> 与えられる $N$ 本の弦の端点はすべて異なり、円周上の番号は $1,2,\ldots,2N$ とする.

答えに寄与する弦だけを残すと、対応する区間は**1本の入れ子の列、または互いに分離した2本の入れ子の列**になる.

区間 $I_i=[L_i,R_i]$ を最外区間とする入れ子の最大本数を $dp_i$ とすると、

$$
dp_i=1+\max_{L_i<L_j<R_j<R_i}dp_j
$$

となる. 右端 $R_i$ の昇順に処理し、左端 $L_j$ を添字に $dp_j$ を区間最大値のセグメント木へ登録すれば、

$$
dp_i=1+\operatorname{seg.prod}(L_i+1,R_i)
$$

で計算して `seg.set(L_i, dp_i)` と更新できる.
全区間を登録した後、左側の列の最外区間 $i$ と、右側の列の最外区間 $j$ を $R_i<L_j$ の条件で組み合わせる.
答えは

$$
\max_i\left(dp_i+\max_{L_j>R_i}dp_j\right)
$$

となる. 右側の列の最大本数は `seg.prod(R_i + 1, 2 * N + 1)` で取得できる.
候補がない場合の最大値を $0$ とすれば、1列だけ選ぶ場合も含められる.
計算量は $O(N\log N)$、空間計算量は $O(N)$.
