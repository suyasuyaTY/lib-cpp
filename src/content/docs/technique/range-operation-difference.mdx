## 1. 概要

「区間 $[l, r]$ に同じ操作をする」をくり返して、数列 $A$ をすべて 0 にする問題を扱う.
次の 2 つの変形をすると、区間操作が「2 点への操作」になり、目標が「差分列をすべて 0 にする」になる.

- 前後に 0 を足して差分を取る: 番兵 $A_0 = A_{n+1} = 0$ を足してから差分列 $D$ を作ると、「$A$ がすべて 0」と「$D$ がすべて 0」が同値になる.
- 区間操作を 2 点操作とみなす: 区間 $[l, r]$ への加算は、差分列 $D$ では $D_l$ と $D_{r+1}$ の 2 点への操作になる. 番兵があるので、どの区間操作もちょうど 2 点への操作になる.

変形した後の問題は多くの場合、貪欲法やグラフの問題として簡単に解ける.
2 つの変形は次のような問題に使える.

- 任意の区間に $+1$ か $-1$ をして、$A$ をすべて 0 にする最小回数を求める.
- 任意の区間に $1$ を加算して $\bmod M$ をとる操作で、$A$ をすべて 0 にする最小回数を求める. 例: [ABC454 F](https://atcoder.jp/contests/abc454/tasks/abc454_f).
- 決められた区間の反転だけを使って、0/1 の列をすべて 0 にできるか判定する. 例: [ABC155 F](https://atcoder.jp/contests/abc155/tasks/abc155_f).

## 2. 前提知識

- 累積和・いもす法（差分列の累積和をとると元の列に戻ること）

## 3. 前後に 0 を足して差分を取る

長さ $n$ の数列 $A_1, \dots, A_n$ の前後に、番兵として $A_0 = 0$ と $A_{n+1} = 0$ を足す.
番兵を足した列から、差分列 $D_1, \dots, D_{n+1}$ を $D_i = A_i - A_{i-1}$ で定める.
特に $D_1 = A_1$、$D_{n+1} = -A_n$ である.

演算が加算でなくても、群の演算であれば同じように定める.

| 区間操作 | 差分の定義 |
| --- | --- |
| 区間に $c$ を加算 | $D_i = A_i - A_{i-1}$ |
| 区間に $c$ を加算（$\bmod M$） | $D_i = (A_i - A_{i-1}) \bmod M$ |
| 区間を反転（XOR 1） | $D_i = A_i \oplus A_{i-1}$ |

番兵を足したので、**$A$ がすべて 0 であることと、$D$ がすべて 0 であることが同値になる.**

また、両端の番兵が 0 なので、$D$ の総和は 0 になる.

$$
\sum_{i=1}^{n+1} D_i = (A_1 - A_0) + (A_2 - A_1) + \dots + (A_{n+1} - A_n) = A_{n+1} - A_0 = 0
$$

$\bmod M$ のときは総和が $\bmod M$ で 0、反転のときは $D$ の XOR が 0（$D_i = 1$ となる $i$ が偶数個）になる.

## 4. 区間操作を差分列の 2 点操作にする

区間 $[l, r]$（$1 \le l \le r \le n$）の各要素に $c$ を足すと、$D$ は次の 2 か所だけが変わる.

$$
D_l \leftarrow D_l + c, \qquad D_{r+1} \leftarrow D_{r+1} - c
$$

$l < i \le r$ では $A_i$ と $A_{i-1}$ に同じ $c$ が足されるので、$D_i$ は変わらない.

加算以外の演算でも、3 章の表の差分の定義を使うと、差分列への操作は次のようになる.

| 区間操作 | 差分列への操作 |
| --- | --- |
| 区間に $c$ を加算 | $D_l \mathrel{+}= c$, $D_{r+1} \mathrel{-}= c$ |
| 区間に $c$ を加算（$\bmod M$） | $D_l \mathrel{+}= c$, $D_{r+1} \mathrel{-}= c$（$\bmod M$） |
| 区間を反転（XOR 1） | $D_l$ と $D_{r+1}$ を反転 |

どの操作も $D_l$ に $c$ を足し、$D_{r+1}$ から $c$ を引くので、$D$ の総和は変わらない.
3 章で示したとおり $D$ の総和は最初から 0 なので、次のことがいえる.

:::note[$D$ を必ず 0 にできる]
任意の区間を選べて、$c$ として任意の値（加算なら任意の整数、$\bmod M$ なら $0, \dots, M - 1$、反転なら 1）を使えるとき、$D$ は必ずすべて 0 にできる. したがって $A$ も必ずすべて 0 にできる.
:::

<Proof>

$i = 1, \dots, n$ の順に、区間 $[i, n]$ に $c = -D_i$ を足す. 区間 $[i, n]$ への操作は $D_i$ と $D_{n+1}$ だけを変えるので、$D_i = 0$ になり、すでに 0 にした $D_1, \dots, D_{i-1}$ は変わらない.
$i = n$ まで操作すると $D_1 = \dots = D_n = 0$ であり、$D$ の総和は 0 のまま変わらないので $D_{n+1} = 0$ でもある.

</Proof>

以上から、問題は次の形に言いかえられる.

> $n + 1$ 個の値 $D_1, \dots, D_{n+1}$ がある. 2 点 $l < r + 1$ を選んで $D_l$ と $D_{r+1}$ に操作する. すべてを 0 にせよ.

選べる区間に制限があるときは、選べる 2 点の組も同じように制限される.
頂点 $1, \dots, n + 1$ を持ち、選べる各区間 $[l, r]$ に対して頂点 $l$ と頂点 $r + 1$ を結ぶ辺を持つグラフを $G$ とおくと、グラフ $G$ の問題になる.
